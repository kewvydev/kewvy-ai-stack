# AI Engineering Stack global catalog

This installation provides optional skills and agent definitions across projects.
It does not initialize projects or impose the stack workflow on them. Follow each
project's own instructions and the user's current scope. Use the stack's ODD,
records and technology profile only where the project was initialized.

Skills are organized through stack-engineering, stack-ui and stack-productivity.
Select only the category needed for the current step; load a specialized skill
only when its stated purpose applies. Backend/API work alone does not call for
UI design, an interview, TDD, SDD or a separate audit. The catalog grants no
permission to expand work or delegate. Use one agent by default; invoke a custom
agent only for an explicitly requested delegation or independent review.
