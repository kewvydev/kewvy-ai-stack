## Resume

Record the last significant outcome, active task, unresolved questions and next
action. Cite existing source records, such as `.ai-stack/tasks.md` or a project's
existing status file, instead of creating another independent task tracker.

## Freshness and verification

When updating, set frontmatter `updated`, `status` and `source_revision` to the
actual date, reviewed state and Git HEAD (or `unavailable`). State uncommitted
changes and evidence limits here. Current code and explicit user decisions take
precedence over this summary. Distinguish local checks, device tests and deployment.
