# Engineering

Ordinary implementation needs no additional workflow. For a difficult reproducible
failure, read [diagnose](../diagnose/SKILL.md); reuse project diagnosing-bugs when
present rather than running both. Read [tdd](../tdd/SKILL.md) when test-first work
is requested. Read [architecture](../improve-codebase-architecture/SKILL.md) only
for an explicitly requested architecture review. Architecture, TDD and debugging
are alternatives for specific needs, not stages of every coding task.

Read only the linked skill needed for the current step, resolving links relative
to this file. If none applies, continue directly. Do not load the whole category,
chain other categories, expand the task or spawn agents because this entry was
selected. Direct requests for a named skill remain valid. Existing skill-specific
approval requirements and project instructions still apply.
